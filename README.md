# DSA in Python + Top 130 LeetCode Problems (Coursera)

This repository is my learning and practice record for the **DSA in Python + Top 130 LeetCode Problems for MAANG Specialization** on Coursera.

## Why this repository exists

I already have prior DSA experience (trees, stacks, queues, BFS/DFS, searching, and related topics), but I have not practiced algorithmic problem solving consistently for nearly two years.

The main goal here is to rebuild problem-solving ability through steady, hands-on practice—not to relearn programming from scratch.

This repo contains my own implementations, solutions, notes, and ongoing progress.

## Specialization structure

1. **Foundations of Data Structures & Algorithms in Python**
2. **Intermediate Data Structures & Algorithmic Patterns**
3. **Advanced Data Structures & Algorithms in Practice**

The courses build progressively: core fundamentals -> intermediate patterns -> advanced application.

## Learning rules

1. Solve problems independently before checking references.
2. Focus on reasoning, not just getting accepted submissions.
3. Write clean Python and analyze time/space complexity.
4. Track patterns and mistakes to improve future performance.
5. Prioritize consistency (roughly one problem per day) over speed.
